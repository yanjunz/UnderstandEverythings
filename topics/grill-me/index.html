grill-me Skill 原理

「给读书会做一个报名页。」如果名额满了，要开放候补吗？只有先知道这个答案，才值得讨论怎么补位。Matt Pocock 的 /grill-me 把这样的依赖整理成设计树，按轮推进，直到你和 Agent 对方案达成共识。[1][2]

试一次设计访谈 查看架构图

读书会报名要不要开放候补？

扮演活动组织者。选择开放候补后，模拟仓库会调查名额释放时能否触发候补补位。活动提醒由组织者手动发送，调查期间仍可决定提前多久发。

问题依赖

  • 是否开放候补
  • 是否发送提醒
  • 提醒时间 ← 发送提醒
  • 补位方式 ← 开放候补＋仓库事实
  • 补位保留多久 ← 自动补位

模拟仓库调查

教学模拟。人工作答推动轮次，侧栏按钮仅模拟工具返回；现场问题由模型判断，演示用固定依赖来展示机制。范围限于候补和提醒。[2]

两种讲解视角

初学者跟着一次报名决策理解追问顺序 架构师分析 Skill 边界、依赖和停止条件

先问会改变后续的问题

/grill-me 是做设计访谈的 Skill。你只要说出想做什么，Agent 就会把可能影响方案的选择列出来。它给建议，由你决定。如果你说「满额即关闭」，后面就跳过怎么补位和给候补者保留多久。[4]

  1. 先问能独立回答的。「要候补吗？」和「活动前要手动发提醒吗？」互不影响，可以一轮问完。当前所有能问的问题合称前沿。
  2. 先查现有能力。你同意候补，Agent 去查有人取消报名时，系统能不能发出名额释放事件。拿到结果才有依据建议自动还是手动补位。因为活动提醒由组织者手动发送，提前多久发可以先定。
  3. 按答案打开下一层。你选自动补位，才出现「给下一位候补者保留多久？」选手动则略过示例里的自动保留时限。
  4. 最后核对共识。没有待答问题、相关调查也到齐时，核对双方理解是否一致。Agent 等你确认后才可据此行动。[2]

哪些问题适合留到原型？

例如候补页面应该怎样排版，光描述可能选不出来。作者文档建议先做可丢弃的原型，用实际体验产生新事实，再回到访谈作决定。[4]

grill-me 怎样决定这一轮问什么？

主 Agent 每轮挑出前提已满足的问题，这一组称为提问前沿。用户决定做什么，子 Agent 查证现有系统能做什么。[2]

角色与系统边界

角色输入输出
宿主用户调用 /grill-me通过 Skill 工具加载 grilling[1]
主 Agent草案、已确认的决定、已查证的事实本轮问题及建议，最后请求确认共识[2]
子 Agent主 Agent 派发的环境查证名额释放事件是否已存在[2]
组织者问题、建议与待确认的方案补位方式等产品决定和最终确认[2]

分轮提问的取舍

减少对话轮次
互不依赖的问题可以成批回答。仓库调查期间，手动提醒这条支路仍能推进。
依赖模型判断
上游用提示词约束前沿和确认时机。模型漏判依赖时，受影响的分支要重新打开。[3]
失效与诊断
同时问怎么补位和保留多久
检查两问间的依赖。保留时长只在自动补位时适用。把它放回后续轮次，保留已确认且无关的提醒决定。[2][3]
查不到名额释放事件
区分「调查还没完成」和「已证实事件不存在」。前者继续等事实，后者可以建议「本期由组织者手动补位吗？」。用户仍可决定增加自动化开发。[2]
暂时没问题就开始实施
先检查是否有待查事实卡住下游。适用分支都解决后，还要取得用户的共识确认。宿主与模型的能力会影响规则是否得到执行。[2][3]
上游实现与输出边界
grill-me/SKILL.md
入口用 disable-model-invocation: true 标明由用户触发，正文要求 Agent 用宿主的 Skill 工具加载 grilling。入口和访谈 Skill 都需要能被宿主发现。[1][3]
grilling/SKILL.md
每轮收集全部可问题目，每问附编号与建议，问句要让回答「是」表示接受建议。可查证的环境事实交给使用新上下文的子 Agent。仍有独立问题时先问这些。[2]
grill-with-docs/SKILL.md
grill-me 的共识留在对话中。若要在仓库维护领域资料，grill-with-docs 会加载同一访谈 Skill 和 domain-modeling。术语进入 GLOSSARY.md。难逆转、缺少背景时会令人困惑且确有取舍的决定，才写成 ADR（架构决策记录）。[4][6]

读者问题

grill-me 的原理是什么？
按依赖组织设计访谈。Agent 把可以查证的事实交给工具调查，把可决定的问题按轮交给用户，收到答案后再重算下一轮。[2]
为什么有的版本一次只问一题？
早期 grill-me 正文明确要求一次问一题。本文固定的上游版本已把访谈抽到 grilling，按前沿成轮提问。相依问题依旧分轮。作者文档仍给出了在 CLAUDE.md 中声明逐题偏好的方式。[5][3]
