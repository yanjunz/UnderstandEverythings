数论 Riemann hypothesis

黎曼猜想

素数有多难预测？

黎曼猜想断言，ζ 函数的每个非平凡零点都位于实部为 1/2 的直线上。若它成立，我们就能更精确地限制估算素数个数时的误差。

100 以内有多少个素数？

素数是大于 1、只能被 1 和自身整除的整数。2、3、5、7 是素数，9 可以分解成 3 × 3。把不超过 x 的素数数一遍，得到的个数写作 π(x)。这里的 π 是函数名，读作「素数计数函数」。

例如，10 以内有 4 个素数，100 以内有 25 个。随着范围增大，素数总体变得稀疏。素数定理说明 π(x) 和 x / ln x 的比值会趋近于 1。ln 表示自然对数。这个定理已经证明。[1]

实际个数是一条阶梯线。每遇到一个素数，π(x) 就加 1。另一种平滑估计 Li₂(x) 把从 2 到 x 的局部密度 1 / ln t 累加起来，写成积分 ∫₂ˣ dt / ln t。图中用数值积分估算它。在 x = 100 时，Li₂(100) ≈ 29.08，比实际多估约 4.08 个。黎曼猜想关系到这种差距随 x 增大可以有多大。

ζ 函数怎么包含素数？

先把输入 s 当成大于 1 的实数。黎曼 ζ 函数把每个正整数的 s 次幂的倒数加起来。输入 2，相当于把 1、1/4、1/9、1/16 一直加下去，结果约为 1.644934。[2]

ζ(s) = 1 + 1/2s + 1/3s + ⋯

ζ(s) = ∏p 为素数 (1 − p−s)−1

同一个函数的两种写法。当 s 是复数时，这两式在实部 > 1 的范围内成立。

第二种写法叫欧拉乘积。以 s = 2 为例，素数 2 对应因子 1 + 1/2² + 1/4² + ⋯，素数 3 对应 1 + 1/3² + 1/9² + ⋯。展开乘积时，可以从这两项分别取 1/4² 和 1/3²，得到 1/12²。因为 12 = 2² × 3，没有另一种选法也得到这一项。

每个大于 1 的整数都有唯一的素因数分解。把所有素数对应的因子乘起来，展开后就给 ζ 的求和式贡献了每个整数恰好一次。这解释了研究一个由正整数写成的函数，为什么能得到关于素数的信息。

猜想说的是哪些零点？

复数可以写成 s = σ + it，其中 i² = −1。把它画在平面上，实部 σ 是横坐标，虚部 t 是纵坐标。不同的输入可以落在同一条竖线上，因为它们的实部相同。

前面的求和式在实部 ≤ 1 时会发散。不过可以用解析延拓把 ζ 定义到整个复平面，只有 s = 1 是极点。解析延拓要求新公式在原来有效的范围内给出相同的值，并在每个非极点附近都能写成收敛的幂级数。这些条件确定了唯一的延拓。[2]

看一个解析延拓的例子

对大于 1 的实数 s，把偶数项的符号全部反过来，会让原来的总和乘上 1 − 21−s。于是 ζ 也可以写成交错级数 1 − 1/2s + 1/3s − ⋯ 除以这个因子。交错级数在 s = 1/2 时仍然收敛，除以 1 − √2 就得到 ζ(1/2) ≈ −1.46035。这个例子展示了换一种公式怎样在原级数发散的地方给出 ζ 的值。[2]

如果某个输入让 ζ(s) = 0，这个输入就叫零点。负偶数 −2、−4、−6、… 是已知的平凡零点。其余零点位于 0 < Re(s) < 1 的临界带。猜想进一步断言，它们全都在带正中的临界线 Re(s) = 1/2 上。[3]

例如，第一个正虚部零点约为 0.5 + 14.1347i。它还有一个关于实轴对称的共轭零点 0.5 − 14.1347i。Platt 和 Trudgian 严格核验了正虚部不超过 3 × 1012 的所有零点都在临界线上。有限高度只覆盖有限多个零点。黎曼猜想断言这对全部非平凡零点成立，至今仍未获证明。[4][5]

零点的位置怎样限制误差？

欧拉乘积提供了入口。对它取对数并求导，会得到一串带权的素数和素数幂。再用复分析把这串求和转换成一个计数公式，ζ 的零点就出现在修正项里。这个关系称为显式公式。[6]

每个零点 ρ 对应一项 −xρ / ρ

若 ρ = σ + it，这项的大小是 xσ / |ρ|。虚部 t 使它随 ln x 改变相位。共轭的两项相加会形成实数振荡。

实部越靠右，xσ 随 x 长得越快。若实部正好是 1/2，增长因子就是 √x。例如 x = 1012 时，x1/2 = 106。如果只把指数换成假设的 0.6，增长因子就约是 1.58 × 107。这两个数字只比较分子的大小，完整误差还要处理无穷多个修正项的叠加。

对素数计数函数，有一个严格的等价说法：黎曼猜想成立，当且仅当估计误差 |π(x) − Li₂(x)| 在充分大的 x 上，始终不超过 √x ln x 的某个固定常数倍。 这说的是整段区间里的素数总数能估得多准。[5]

从欧拉乘积到素数计数

要把 ζ 的零点和素数计数联系起来，可以先计算 ψ(x)。每个不超过 x 的素数幂 pk 贡献一次 ln p。以 x = 10 为例，直接加权计数得到约 7.8320。沿 ζ 函数也能得到同一个结果。

负对数导数与显式公式

在 Re(s) > 1，欧拉乘积给出 −ζ′(s)/ζ(s) = ∑p,k≥1 ln(p) p−ks，其中 p 遍历素数。把它乘上积分核 xs/s，沿右侧竖线做反演积分。将积分路径向左移动时，ζ 在 s = 1 的极点给出主项 x，非平凡零点给出修正项。[6]

先按 ln p 的权重数不超过 x 的素数幂 pk，得到函数 ψ(x)。在跳跃点，用跳前和跳后的平均值定义 ψ₀(x)。对 x > 1，冯·曼戈尔特显式公式是：

ψ₀(x) = x − ∑ρ xρ/ρ − ln(2π) − ½ ln(1 − x−2)

这里的求和按重数计入非平凡零点，并把虚部的绝对值限制在同一高度内，再让该高度趋于无穷。公式左侧是带权计数，需再处理素数幂和权重，才能回到 π(x)。公式中 ln(2π) 的 π 是圆周率。[6]

把 x 设为 10。直接列出素数幂 2、3、4、5、7、8、9，分别加上底数的自然对数，可得 ψ₀(10) ≈ 7.8320。在右侧，先算主项和两个对数项，合计约 8.1671。第一对共轭零点的贡献是 −0.4110，加入后得到约 7.7561。这个截断示例展示了一对零点怎样改变估计。
